## What is John the Ripper? ##
Not to be confused with "Jack" the Ripper of course! 
_John the Ripper_ is a free open-source software tool that's used for password security auditing, and password recovery. It works by taking encrypted password data (or hashes) and tests different guesses to see which word matches. Security experts and system admins use it to find weak passwords on a network.
